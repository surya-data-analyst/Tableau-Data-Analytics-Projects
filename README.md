# Project 1 – Sales Dashboard

## Overview

This project is a Tableau sales analysis dashboard created to explore sales performance across regions, categories, sub-categories, and time periods.

## Tool Used

* Tableau

## Key Analysis

* Sales performance by Region
* Sales comparison by Category
* Sales by Sub-Category
* Sales trends over time
* Top-performing sub-categories
* Interactive dashboard filtering

## Tableau Skills Demonstrated

* Data visualization
* Dashboard creation
* Filters
* Charts and visualizations
* Trend analysis
* Sales analysis
* Business insights

## Key Business Insight

The dashboard helps identify differences in sales performance across regions and product categories and highlights areas that can be investigated further for business decision-making.
